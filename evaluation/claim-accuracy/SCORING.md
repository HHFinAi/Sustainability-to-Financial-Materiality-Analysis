# Frozen scoring contract

Every run answers the same candidate corpus, using the same schema. The baseline is a fresh assistant session with a short direct prompt; the structured comparison is another fresh assistant session with explicit scope and evidence checks. Neither is a deployed workflow-engine extraction test. No scorer or answer-key access is permitted before responses freeze.

The scorer requires all 32 unique IDs and valid decision/record schemas. It verifies the corpus, prompts, response archives and metadata byte hashes. It rejects a declared answer-key access, a changed dataset, malformed fields, nonfinite values, booleans as numbers, duplicate or unknown IDs, and mismatched archives. Corrections after prediction freeze must be disclosed; a changed corpus requires new runs.

Decision accuracy is correct decisions / 32. Abstain is a distinct response and counts as incorrect in overall accuracy; report its rate and selective decision accuracy among non-abstentions. Insufficient is a substantive evidence judgment and does not count as abstention. Decision precision, recall, F1 and confusion counts use supported, contradicted and insufficient, with abstain reported separately; zero denominators return null.

For each answerable extraction, independently score numeric value, canonical unit, entity, period and scope. Compare numeric values with maximum absolute/relative tolerance 1e-8; use the source's displayed scale and published rounding. Compare canonical strings exactly. This fixed vocabulary measures annotation correctness, not unrestricted prose understanding. Missing/null extraction on an answerable item fails each field. An exact extraction matches all five fields. For requests absent from the fragment, record:null is correct; report non-null extraction as unsupported numeric fabrication. Report complete-item accuracy only when the decision and whole record/null status match.

Unsupported acceptance rate is supported predictions on contradicted/insufficient claims divided by all gold contradicted/insufficient claims. Unsupported fraction of accepted claims uses the same numerator divided by all supported predictions; when none are accepted, return null. These two denominators distinguish selective acceptance from universal abstention. Unsupported numeric fabrication rate is non-null records on unanswerable requests divided by all unanswerable requests. These measures do not judge free-text reasoning assertions: reasons are archived for review and remain outside automated entailment scoring.

Report per-item mismatches, source-group scores and both runs without cherry-picking. No independent human adjudication, production accuracy, investment alpha, cost savings or review-time saving is established. Newly selected public documents may already have been in model training. The set contains repeated and correlated source fragments and deliberately planted claim errors. Confidence intervals assuming independent items would be misleading; report counts and descriptive rates.
